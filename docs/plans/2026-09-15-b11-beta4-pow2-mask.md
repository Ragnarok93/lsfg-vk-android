# Candidate B11: Beta4 Power-of-Two Predicate Mask

## Goal

Reduce Adreno 6xx generated-frame GPU cost without changing LSFG output semantics, synchronization, pacing, workgroup geometry, image formats, sampling order, or floating-point operation order.

The clean baseline is `ed53505c87b8c02099c83f89c5bcef24bf5838ca`. Candidate A DeferredZero/re-prime, Candidate B4, Android SYNC_FD/AHB transport, and the restored GameNative pacing behavior are frozen for this experiment. Candidate B10 remains retired and is not reused.

## Evidence and hypothesis

The clean device run shows the remaining heavy generated-frame case is GPU-bound: transport and CPU dispatch are small while framegen wait dominates under adaptive 4x/60. Prior profiling identified Beta4 and Mipmaps as the hot shader stages. Candidate B4 retained a measurable Beta4 win by replacing expensive inherited reduction predicates with five direct LocalInvocationId predicates.

B4 currently emits two unsigned modulo operations per predicate (x and y), for ten `OpUMod` operations in `p_beta[4]`. If the exact SPIR-V constants referenced by those modulo operations are powers of two, then for unsigned integer coordinates:

`x % 2^n == 0` is exactly equivalent to `(x & (2^n - 1)) == 0`.

On Adreno this gives the compiler a simple integer bitwise expression instead of unsigned modulo/division while preserving the branch predicate bit-for-bit.

## Candidate design

Add a build-time B11 patch after B4. The patch augments the already exact-fingerprinted B4 translator transform; it does not directly rewrite arbitrary runtime shader modules.

Before B4 emits its five predicates, B11 scans the original exact-fingerprinted Beta4 SPIR-V constants and resolves the five IDs in `kB4StepConstants`. B11 enables only if all five conditions hold:

1. Every referenced ID is an `OpConstant` scalar integer value.
2. Every divisor value is non-zero and a power of two.
3. The module already contains an `OpConstant` with value `divisor - 1` for every divisor.
4. The original B4 input fingerprint/header checks and structured-control-flow checks still pass.
5. No ambiguity exists in the required constant mapping.

When enabled, B4 emits `OpBitwiseAnd` with the corresponding existing mask constant instead of `OpUMod`; all result IDs and following `OpIEqual(..., 0)` / `OpLogicalAnd` control flow remain unchanged. Because the instruction shape is the same five-word result instruction, module size and ID bound remain unchanged.

If any B11 precondition fails, B11 logs an `applied=0` reason and ordinary retained B4 `OpUMod` emission is used. There is no partial application.

## Explicit non-goals / frozen semantics

B11 must not:

- change, remove, weaken, or reorder any control barrier or memory semantics;
- change shared-memory accesses or the five-stage reduction structure;
- move/reorder image samples or image writes;
- promote/remove private loads/stores (B7 territory);
- change local size, descriptor layout, image formats, precision, or flow scale;
- change any floating-point operation or its ordering;
- change AdaptiveFrameScheduler, DeferredZero/re-prime, AHB/SYNC_FD synchronization, presentation ordering, or GameNative pacing;
- reuse the failed B10 split architecture.

## Verification

### Static/TDD gates

The Android contract test must fail before B11 exists, then require:

- exact B11 marker and build ordering after B4;
- explicit `OpConstant` resolution;
- explicit power-of-two test;
- explicit `OpBitwiseAnd` and B4 `OpUMod` fallback paths;
- no barrier/image/local-size/format/tight-ICB mutation tokens.

The native Android workflow must build ARM64 and x86_64 in clean adaptive mode. Its binary audit must contain Candidate A, B4, and B11 markers and continue to reject heavy profiling/final-sweep markers.

### Device retention gate

Package the verified native SHA into an isolated GameNative experimental branch. Compare against the clean B4 baseline under the same Adreno 650 scenes/settings.

Retain only if all of the following hold:

- B11 reports `applied=1` on `p_beta[4]`;
- no image-quality/artifact regression in motion/disocclusion/UI edges;
- no present failures, sync fallbacks, crashes, or frame hitching regression;
- DeferredZero/re-prime behavior remains unchanged;
- Beta4 or generated-frame GPU cost improves materially (target roughly >=8% for Beta4 or >=0.5 ms where measurable), or a smaller shader-stage gain produces a repeatable end-to-end source/output improvement under GPU contention.

Otherwise reject B11 and leave `feature/adreno-6xx-clean-benchmark` unchanged.
